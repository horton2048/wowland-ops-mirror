# 社群定位&长期建设目标

**WowLand，是陪大学生真实开始、持续生长的成长世界。**

WowLand面向大学生带来三个系列活动品牌，支持大学生在行动中成长，让想法落地、让创造被看见。

- **抖音AI创变者计划——让创意照进现实**为大学生打造的AI创新实践平台，支持技能提升、产品与作品创作，连接真实产业与职业机会。
- **WowLand｜成长现场——向世界生长，向自己扎根**属于大学生的行动与社交场域，通过真实经验、具体行动和社交连接，解决困惑、找到方向。
- **WowLand｜野生创作Camp——你看见了世界，世界就会看见你**属于大学生的内容创作舞台，从自己真实生活出发，也走进更广阔人生样本，创作真诚、好看、有价值的内容。

同时，依托抖音，WowLand将根据具体项目提供方法与导师指导、流量扶持和项目资源支持，以及相关工作机会。

## **社群运营人需要做什么？**

**大家会作为校园常设群的群管理员。**

**你需要持续吸引社群成员加入，支持WowLand活动开展，打造一个WowLand专属阵地：**

| **职责** | 需要完成的动作 |
|-|-|
| **持续招新** | 结合官方招募和本校渠道，持续邀请真正感兴趣的同学加入，扩大本校社群的成员基础 |
| **维系社群成员和秩序** | 审核新成员，及时回应问题并维护群内秩序 |
| **组织社群参与活动** | WowLand会发布项目机会，向成员讲清参与方式和时间节点，定向邀请合适的人报名，并跟进参与 |
| **发起社群专属活动** | 根据本校成员的兴趣和需求，组织线下社交聚会、看片会、主题交流等活动（项目组会提供一套精心设计的有趣活动玩法，SOP、活动资源支持供后续大家取用） |
| **记录与复盘** | 记录增长、真实交流、整理出成员故事或社群内容，让优秀成果被更多人看见，逐步建立稳定的社群关系 |

*\*平台项目会由项目组提供统一的项目说明、招募物料、时间节点和群内发布内容。*

*社群运营人负责结合本群情况完成发布、解释、定向邀约、参与组织。*



## **社群运营人可以获得什么**

加入WowLand、负责社群运营后，你就正式成为一名 **Wow 发起人**。**你将：**

**获得正式的社群运营身份及相应管理权限**

- 获得社群管理权限、参加社群运营、活动组织及团队协作等专项培训
- 可根据实际活动申请经费、物料、嘉宾及传播支持

**做出结果，有运营激励**

- 完成基础运营职责并达到要求后，可获得按月发放的运营津贴（根据负责社群规模和质量确定）
- 运营能力和结果经过验证后，可以负责更多社群或更大项目，并获得相应资源和激励

**运营成果将作为后续成长、专项激励和重点机会推荐的重要依据**

- 运营成果突出的人，可以申请更多活动经费、嘉宾和传播资源
- 优先参与伙伴大会、AI实践营、职业辅导、品牌活动和重点项目共创
- 表现优秀者可以承担更大的跨校项目，并进入实习及工作机会的择优推荐范围

## 社群运营人长期成长路径

从**Wow发起人**出发，在接下来的半年里，表现优秀的发起人有机会晋级为 **L4 Wow 领航者**，担任本校 WowLand 的总负责人，统筹 AI 相关活动、WowLand 原有活动以及社群运营。



所有加入群聊的人，就是社群的**Wow好奇星人（L1）**啦\~  大家都可以通过活跃社群、参与活动、创作内容等多种方式来解锁新身份，随着参与的深度和广度更大，解锁的身份与权益也会对应递进！

**Wow奇遇者（L2）**

- 参与各类社群活动、做出作品/成果，在社群中分享想法与经验，带动更多人交流和尝试。
- 优秀成果有机会获得活动激励、进入抖音生态并获得传播支持，部分项目提供官方实践证明。

**👉🏻（你现在在这里🙋🏻‍♀️） Wow发起人（L3）** 

- 策划并落地各类活动、或运营WowLand社群，持续招新、扩大规模、促进交流与项目参与。
- 可获得培训、资金及其他资源支持，表现优秀可获得实践证明、专项激励，并优先参与AI实践营、1V1职业辅导。

**Wow领航者（L4）**

- 在校园组建并带领团队，统筹本校WowLand活动与社群运营。
- 获得项目与团队运营的资源支持，参加抖音品牌活动及WowLand伙伴大会，表现优秀可参与全国性活动策划、获得专项激励、获得实习机会。

**Wow造梦官（L5）**

- 与抖音校园核心团队共同规划WowLand的发展，在重大项目中承担关键职责，推动创意与计划落地。
- 参加抖音品牌活动及WowLand伙伴大会，共创全国性项目；有机会直通抖音项目、实习与工作机会。

此外，**Wow发起人、Wow领航者、Wow造梦官** 还将不定期解锁专属的**创意狂欢舞台**和**职场奇遇局**，比如：**「今日宜黑客松」**、**「今日宜改简历」**、**「职业技能开箱局」**……

# ⚠️⚠️  社群注意事项（不允许发生的）⚠️ ⚠️ 

**招募与品牌使用**

- 不得在任何盈利性质的场景中使用品牌开展宣传。
- 可以与校内其他社团开展非盈利联合活动，方案、分工及品牌使用需提前与项目组确认，并遵守学校管理要求。
- 社群由官方账号统一创建，不得以个人名义私自建群或设立同名衍生群，不得擅自修改官方统一设置的信息。
- 对外如实说明自己运营身份，不得冒用官方名义、超出授权作出承诺，或未经授权代表官方与第三方达成合作.
- 活动、奖励、证书、实习及工作机会等信息，以官方确认的口径为准，不得发布未经核实的信息或夸大权益。

**运营诚信底线**

- **WowLand项目不向学生收取任何费用。** 有活动经费需求，按项目组流程申请，不得自行向参与者筹集。
- **数据必须真实。** 禁止买粉、刷量、小号互刷、机器人互动及伪造活动记录。增长和互动必须来自真实同学，入群、报名、实际参与人数分别据实记录。
- **不得利用运营身份谋取个人私利。** 不得私自向成员收费、售卖商品、组织付费活动、收取返佣，或借品牌及社群资源开展个人经营。

**群内内容与秩序**

以下行为严禁出现：

- **商业广告与无关引流**：推销、卖课、返佣推广，以及用于商业推广或无关引流的外部二维码、链接。
- **诈骗与虚假信息**：虚假招聘、虚假福利、诱导转账及其他欺骗性内容。
- **违法违规内容**：违反法律法规及平台规则的内容，包括违规低俗、暴力内容。
- **攻击与骚扰**：人身攻击、歧视、恶意挑起群体对立，以及私信骚扰。
- **交易与代办信息**：代课、跑腿接单、拼单、二手交易等。社群不是交易平台或便民信息发布板。
- **干扰正常讨论**：刷屏、重复发送、恶意灌水。
- **侵犯隐私与作品权益**：未经同意，外传成员个人信息、聊天记录、照片或作品。

与社群主题相关的学习求助、经验分享、作品交流及资料链接不得夹带商业推广、侵权资源或作弊代办。

**社群违规处理**

- **一般违规**：及时制止，视情况撤回或要求删除内容，按“提醒 → 警告 → 移出”处理。
- **严重违规**：广告号、诈骗、严重骚扰等可直接移出并上报项目组；必要时在群内说明违规类型，提醒成员防范。
- **运营人违规**：由项目组核查，视情况暂停或取消运营权限，并安排社群交接。

所有处理应依据明确规则，说明原因，不公开羞辱成员、不扩散隐私。有争议或无法判断的情况，交由项目组处理。





# 常见问题 Q&A

**Q：可以和校内社团一起招新、办活动吗？**

可以开展非盈利联合活动。提前与项目组确认方案及品牌使用，并遵守学校要求，不得夹带销售、收费或商家引流。



**Q：商家愿意提供优惠券、礼品，可以用来吸引同学入群吗？**

不可以自行开展这类合作，也不能承诺品牌曝光作为交换。官方提供的活动激励和学生权益，按统一安排发布。



**Q：可以自己策划活动吗？哪些需要先确认？**

可以提出想法、策划活动。日常群内交流按运营方案开展；

涉及品牌对外宣传、线下活动、第三方合作或经费使用，需提前向项目组确认。



**Q：活动有成本，可以收费、收押金或组织AA吗？**

不得以WowLand活动名义自行收费、收押金或要求AA。

有费用需求，先向项目组申请支持；未确认前不垫付、不承诺报销。



**Q：可以按社群特色起名字、修改介绍吗？**

可以提出命名和介绍方案，在项目组允许的范围内完善。不得擅自修改统一设置的信息，或另建同名群承接成员。



**Q：招募时可以说“有证书、有实习机会”吗？**

只介绍已确认、适用于该项目的权益。“有机会获得”不能说成“保证获得”，不得自行增加条件或承诺名额。



**Q：群里能分享资料、作品链接、找搭子吗？**

可以开展与学习、职业探索、创作及活动有关的求助和交流。不禁止正常资料分享，但不得借机卖课、引流、传播侵权资料或提供作弊代办；不发布代课、跑腿接单、拼单、二手交易信息。



**Q：可以把群内故事、截图和作品用于宣传吗？**

可以征集，但须先取得相关成员同意，说明发布渠道和用途，遮挡不必要的个人信息。不能因为内容发在群里，就默认可以对外使用。



**Q：遇到拿不准的情况怎么办？**

把具体方案、合作对象、是否涉及费用及希望使用的品牌资源发给项目组，确认后再执行。



**Q：是否能以WowLand形式注册官方社团/协会？**

不允许使用官方名字，但是可以申请自己的社团承接活动。
